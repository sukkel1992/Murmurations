# Publiceren via GitHub Pages

De site is een statische pagina en wordt rechtstreeks vanuit de repository gepubliceerd.

1. Push de wijzigingen naar de `main`-branch.
2. Open **Settings → Pages** in GitHub en kies bij **Build and deployment** als bron **GitHub Actions**.
3. Wacht tot de workflow **Deploy to GitHub Pages** is afgerond.
4. Deel de gepubliceerde URL: <https://sukkel1992.github.io/Murmurations/>.

De workflow draait automatisch bij iedere push naar `main` en kan ook handmatig worden gestart via **Actions → Deploy to GitHub Pages → Run workflow**.
